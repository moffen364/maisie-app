HOW THE PROMPTS WORK

Each section loads its own file — e.g. prompts/exercise.md. You edit that file to tune how Claude behaves for that section. The app reads it fresh each Sunday, so changes take effect immediately.

Example prompt files: exercise.md · meals.md · todos.md · social.md · events.md
